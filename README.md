# 💰 Note Taking App

An Android application built using **Kotlin** and **Jetpack Compose** that helps users to remember and track their daily routine efficiently with a clean and modern UI.

## 📱 Features
- Add, update, and delete Tasks
- Offline data storage
- Clean and user-friendly UI
- Fast and lightweight performance


## 🛠 Tech Stack
- **Kotlin**
- **Jetpack Compose**
- **Room Database**
